# Self-hosted fonts

Vendored from Fontsource npm packages version 5.3.0: @fontsource-variable/geist, @fontsource-variable/geist-mono, @fontsource-variable/inter, @fontsource/kalam, @fontsource-variable/manrope, @fontsource-variable/lora, @fontsource/instrument-serif, @fontsource-variable/playfair-display, @fontsource-variable/cormorant-garamond.

SIL Open Font License files are included per family. CSS retains upstream Unicode ranges and swap display. The eight layout families and the landing page's Cormorant Garamond remain available without build-time Google requests. Main Latin faces are preloaded; other faces load only where used. File SHA-256 hashes are recorded in manifest.json.

To update, obtain the corresponding published npm archives, copy referenced WOFF2 files and licenses, regenerate CSS paths and hashes, then verify browser typography and build with external font hosts blocked.
