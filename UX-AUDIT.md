# D.Scribe UX Audit — 2026-03-29

## CRITICAL

1. **Pipeline reads like a developer checklist, not a journey**
   - "03 — ANALYZE: Extract key points, voice profile, mind map" means nothing to Chiara's mom
   - Fix: Rewrite in human language, collapse future steps, show only what's next

2. **Transcript page is a wall of 8,889 words with no breaks**
   - "Speaker 0" label in red, no paragraphs, no timestamps
   - Fix: Break by speaker, add "Your 8,889 words, captured" as a celebration, add guidance copy

3. **"Key points failed" error will make non-tech users close the browser**
   - Pink background + "failed" = "I broke it"
   - Fix: Warm recovery language, terracotta not red, "Still working on it — give it another try"

## HIGH

4. **Upload page — three equal options creates paralysis**
   - Lead with "Upload audio file" as primary, deprioritize live recording

5. **No celebration at completed steps**
   - Transcribing 8,889 words should feel like an achievement, not a database update

6. **Dashboard subtitle is product marketing copy, not a welcome**
   - Replace with contextual message based on user state

## MEDIUM

7. **Analysis "What happens next?" is below the CTA**
   - Move it above so users know what their credit buys

8. **"Analyze (1 credit)" centers cost over value**
   - Try "Find my key ideas"

9. **"Speaker 0" → "You"**
   - Or let user name speakers
